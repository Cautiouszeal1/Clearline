# Clearline

Bulk clean your X (Twitter) account — delete posts and replies, undo reposts, and remove likes — straight from your own browser.

Clearline is a single static page. You choose what to remove (with date filters, keep-words, pinned-post protection and a dry-run mode), and it generates a script you paste into the console of your own logged-in x.com tab. No passwords, API keys or servers.

## Use it
1. Open `index.html` (or the GitHub Pages site) and set your options.
2. On a desktop browser, open `x.com/<you>/with_replies` and/or `x.com/<you>/likes`.
3. Press F12 → Console, paste the script, press Enter. Use the on-page panel to stop.

## Notes
- Deletions are permanent — download your X archive first.
- Unofficial tool; automation may be against X's rules and can trigger rate limits or temporary locks.
- It clicks X's own buttons, so changes to X's layout can break it. Run a dry run first.
- The Likes tab only loads a limited history, so very old likes may be unreachable.
