# Clearline

Bulk clean your X (Twitter) account — delete posts and replies, undo reposts, and remove likes — straight from your own browser.

Clearline is a single static page. You choose what to remove (with date filters, keep-words, pinned-post protection and a dry-run mode), and it turns your settings into a one-click bookmark you run on x.com. No passwords, API keys or servers.

## Use it
1. Open the site and drag the **🧹 Clearline** button to your bookmarks bar (Ctrl+Shift+B shows the bar).
2. Open x.com on a desktop browser while logged in.
3. Click the bookmark, then press **Start**. It finds your username itself, cleans posts, replies and reposts, then your likes. Press **Stop** any time.

A copy-paste console script is also available under Settings if your browser blocks bookmarklets.

## Notes
- Deletions are permanent — download your X archive first.
- Unofficial tool; automation may be against X's rules and can trigger rate limits or temporary locks.
- It clicks X's own buttons, so changes to X's layout can break it. Run a dry run first.
- The Likes tab only loads a limited history, so very old likes may be unreachable.
